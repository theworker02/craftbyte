# craftbyte

Craft and reshape byte text streams with deterministic transforms.

**Site:** https://theworker02.github.io/craftbyte/

## Install / run

```bash
git clone https://github.com/theworker02/craftbyte.git
cd craftbyte
node src/cli.js
node --test
```
